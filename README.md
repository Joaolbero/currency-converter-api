# Conversor de Moedas com API / Currency Converter (API)

**PT-BR**  
Conversor de moedas em Python usando a API pública exchangerate.host, com CLI simples. **Sem venv**.

**EN**  
Python currency converter using the public exchangerate.host API, with a simple CLI. **No venv**.
